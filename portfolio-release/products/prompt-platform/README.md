## The product

Prompt presents a marketplace and community for AI prompts, agent skills and creative systems. Its explore page organizes discovery by resource type, model and subject.

## How to get started

| Step | Action |
|---|---|
| 01 | Open Explore |
| 02 | Choose a resource type |
| 03 | Select model and category filters |
| 04 | Review available results |

## Core capabilities

| Area | What it offers |
|---|---|
| **Resource types** | Explore text, image, video, audio and agent skills. |
| **Model filters** | Narrow discovery by AI model. |
| **Categories** | Browse creative and professional subjects. |
| **Price filters** | Distinguish free and paid resources. |
| **Rating filter** | Filter by minimum rating. |
| **Marketplace discovery** | Combine the available filters. |

## Who it is for

AI users, creators and professionals looking for reusable creative resources.

## Practical scenario

A creator narrows discovery to a resource type and model before reviewing available listings.
