## The product

ClockScript is a workout operating platform for group studios, coaches and home athletes. It connects an exercise library with reusable training blocks, workout composition, timer previews and a full-screen TV experience.

## How it works

| Step | Action |
|---|---|
| 1 | Create and tag exercises |
| 2 | Build timed or repetition-based clusters |
| 3 | Compose the workout and preview its sequence |
| 4 | Start the session on the TV display |

## Core capabilities

| Area | Capabilities |
|---|---|
| **Exercise library** | Organize movements with images, GIFs or videos. |
| **Clusters** | Combine timed, repetition and rest rows. |
| **Workout composition** | Arrange blocks and rounds. |
| **Timer preview** | Review the sequence before starting. |
| **TV display** | Show countdown, current movement and next exercise. |
| **Live demo** | Explore the public display example. |

## Who it is for

Group fitness studios, coaches and home athletes who need structured workout execution.

## Practical scenario

A coach prepares movement blocks before class, reviews the timing and runs the workout on a shared screen so the group can follow the sequence.
