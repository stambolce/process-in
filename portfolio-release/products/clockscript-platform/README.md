## The product

ClockScript is a workout operating platform for group studios, coaches and home athletes. It connects an exercise library with reusable training blocks, workout composition, timer previews and a full-screen TV experience.

## Turn a prepared workout into a session the room can follow

A coach needs to prepare the workout and guide the class through it. Timings, repetitions, rest periods and the next movement all have to stay understandable while the session is running.

ClockScript connects preparation with execution. Exercises hold the movement and its media; clusters organize time, repetitions and rest; workouts arrange those blocks into the session. The timer preview lets the coach inspect the sequence, and the TV mode presents the countdown and exercise context to the room.

### Who benefits in practice

A group studio can prepare a class before participants arrive. A coach can reuse movement blocks when composing the next workout. A home athlete can organize a session around the same exercise and timing approach.

The purpose is to make the prepared structure usable during the actual workout. Build the movements, assemble the blocks, check the sequence and then run the display while coaching or training.
