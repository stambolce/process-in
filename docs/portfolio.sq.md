# PROCESS IN — Katalogu i produkteve

[Македонски](portfolio.mk.md) · [English](portfolio.en.md) · [Shqip](portfolio.sq.md) · [Türkçe](portfolio.tr.md)

Produkte dhe platforma të organizuara sipas qëllimit. Të gjitha statuset LIVE janë konfirmuar nga pronari.

Regjistri fillestar përmban 41 domene. CreativeDesk/Magical dhe MailBoost/PowerInbox janë marka të lidhura. REZERV dhe INHOST janë prezantime shtesë jashtë atij regjistri. Frilenseri dhe Workplace ndajnë të njëjtën platformë në dy domene.

Viza në kolonën GitHub tregon mungesë prezantimi të veçantë, jo ndryshim të statusit LIVE. SalesBoost është shtyrë me kërkesën e pronarit.
