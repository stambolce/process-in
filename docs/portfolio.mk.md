# PROCESS IN — Каталог на производи

[English](portfolio.en.md) · [Македонски](portfolio.mk.md)

Независни производи и платформи, организирани по намена. Сите статуси LIVE се потврдени од сопственикот.

Оригиналниот регистар содржи 41 домен. CreativeDesk/Magical и MailBoost/PowerInbox се поврзани брендови и се претставени еднаш. REZERV и INHOST се дополнителни постојни презентации надвор од тој регистар.

Цртичка во колоната GitHub значи дека самостојната презентација сè уште не е објавена; не го менува LIVE статусот на производот.
